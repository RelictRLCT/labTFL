# Фазз-модуль для PDA

## Руководство:

- В файл `rules.txt`, находящийся в корне проекта, нужно ввести грамматику
в соответствии с синтаксисом из слайдов лабы.
  - **Пример:**
    ``` 
    S -> SbSa 
    S -> aSSb 
    S -> b 
    S -> bS 
    ```
- В файле `settings_of_generation.txt` можно менять настройки генерации тестов:
  - **Параметры генерации:**
    - `probability_of_random_next_term` - вероятность выбора случайного следующего терма, 
  не согласованного с матрицей биграмм. При установке этого параметра в 0 будет очень маленькая вероятность того, 
  что слова, не принадлежащие языку, вообще сгенерируются, так как такое будет возможно только в случае
  превышения максимальной длины слова, которая также задаётся через параметры.
  При установке в 1 термы будут вообще не согласованы с матрицей биграмм. По умолчанию `probability_of_random_next_term=0.2`.
    - `probability_of_not_end_when_final_symbol_found` - вероятность продолжения генерации слова
    при достижении завершающего символа. При установке в 0, скорее всего, будет невозможно
    сгенерировать много подходящих слов для грамматики. При установке в 1 генерация слова будет
    продолжаться, пока не будет достигнута максимальная длина.
    По умолчанию `probability_of_not_end_when_final_symbol_found=0.5`.
    - `max_length` - максимальная длина генерируемых слов.
    По умолчанию `max_length=40`.
    - `max_time` - максимальное время ожидания генерации (в секундах).
    Если переданный язык имеет всего несколько слов, например, `S -> aaba`, а 
    запрошено, к примеру, 5 слов, входящих в язык, то просто сработает отсечка по времени.
    В случае сложных правил также возможна отсечка по времени и вывод всех найденных слов,
    даже если их меньше, чем требовалось.
    По умолчанию `max_time=30`.
    - `count_from_lang=5` - количество слов, которые входят в язык.
    - `count_not_from_lang=5` - количество слов, которые не входят в язык.
    
- Для запуска в корне проекта надо выполнить команду:
```bash
python3 main.py
```
- Результаты генерации будут выведены в файл `tests.txt` в соответствии
с синтаксисом, указанным на слайдах лабы.
  - **Пример содержимого файла `tests.txt`:**
    ```
    bbbb 1
    abbb 1
    bbb 1
    b 1
    bb 1
    ba 0
    ab 0
    aabab 0
    a 0
    aa 0
    ```
