# Вариант 1: захват групп и захват строк (проверка корректности + каркасная КС-грамматика)
- Регекс вводится в файл `regex.txt` в корне проекта, 
например, `(ab)(\1)\2`. 
- Также есть два файла с тестами: `tests_correct.txt`
и `tests_incorrect.txt`. При запуске программы можно
выбрать режим работы (получение одного регекса из
`regex.txt` или автоматический прогон тестов, в случае
с автоматическим прогоном деревья грамматики сохраняться
 в файл не будут).
- После запуска программы
сначала проверяется корректность синтаксиса 
(синтаксис операций, баланс скобок и т.д.).
  - Если синтаксис корректен, выполняется проверка
  правильности использования ссылок на группы и строки.
    - При успешных проверках в консоль выводится 
    каркасная КС-грамматика.
- Для запуска программы сначала необходимо установить
пакет `graphviz`:
```bash
pip install graphviz
```
После установки пакета в корне проекта необходимо 
запустить программу командой
```bash
python3 main.py
```
и выбрать режим работы: 
- 1 - получение одного регекса из `regex.txt`
- 2 - автоматический прогон тестов из двух файлов
## Этапы работы программы
### 1. Проверка синтаксиса 
- На первом этапе проверяется баланс скобок, 
правильность использования `\` (за ним должна 
следовать только цифра), принадлежность каждого 
символа предопределённому алфавиту символов, 
правильность ипользования `?`, `:` и `*`.
### 2. Построение дерева регекса
- На втором этапе парсер строит дерево регекса,
оборачивая все группы и ссылки на группы 
(включая незахватывающие), 
использование `\num`и последовательности символов
в конкатенации, разбивает альтернативы на дочерние 
ветви и обрабатывает итерации (`*`). 
- Для отладки полученное дерево с помощью 
`graphviz` сохраняется в файл `tree_view.png` 
в корне проекта, если 
программа запущена в режиме анализа одного 
регекса из `regex.txt`.
### 3. Проверка правильности использования захватов групп и строк
- Затем проверяется, все ли номера используемых групп
существуют.
- Если всё в порядке, запускается функция анализа
выражения на то, все ли захваты строк ссылаются
только на полностью инициализированные группы. Для 
этого рекурсивно обходится дерево и проверяется, 
инициализированы ли все пути разбора для групп, 
на которые ссылаются `\num`.
### 4. Построение КС-грамматики по дереву
- При успешном анализе регекса по полученному 
дереву строится КС-грамматика.
- Каждый узел дерева оборачивается в новый нетерминал 
`Xi`.
  - Если узел дерева представляет группу, то создаются 
  нетерминалы `Gnum` с номером, соответствующим 
  номеру группы.
  - Если узел дерева - ссылка на группу или 
  захваченную строку, то ему присваивается уже 
  существующий нетерминал для соответствующей 
  группы (для ссылки на строку он гарантированно 
  существует, так как регекс уже проверен).
  - Если же узел дерева - ссылка на группу, которая
  встречается раньше, чем сама группа, то для группы
  также создаётся нетерминал `Gnum`, но словарь 
  с грамматикой заполняется продукциями уже при
  встрече самой группы.
- Полученная грамматика выводится в консоль.
### Замечания:
- Построенная грамматика не в ХНФ, хотя это легко 
сделать, прикрутив 3 лабу. В получаемой грамматике
легче отслеживать группы захвата и проверять логику 
парсера.
- Могут быть повторяющиеся правила с разными 
нетерминалами, например:
```
X1 -> a
X2 -> a
X3 -> a
```
