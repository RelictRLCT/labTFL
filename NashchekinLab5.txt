Коммутативный образ языка - это?
________________________________________________________________
Пусть Σ = {a_1,..., a_m} - алфавит. Коммутативный образ слова w из языка Σ∗ — это вектор,
записывающий количество символов каждого типа: Ψ(w) = (|w|a_1,..., |w|a_m).
Операция распространяется на языки поэлементно: Ψ(L) = { Ψ(w) | w лежит в языке L} - коммутативный образ языка L.
Например, рассмотрим язык (ab)* и язык Дика. Язык (ab)* - регулярный, язык Дика - нерегулярный. 
У обоих языков один и тот же коммутативный образ: {(n, n) | n >= 0}.

Также существует эквивалентное определение коммутативного образа языка, которым может быть удобно 
пользоваться при исследовании свойств языков. 
Коммутативный образ языка L - это такой язык L', что для любого слова w из языка L существует единственное 
слово w' из языка L', такое, что для любого терминального символа γ из алфавита Σ ⇒ |w|γ = |w'|γ 
(количество символов γ в слове w совпадает с количеством этих символов в слове w'). 
Например, для языка a^n b^n коммутативный образ - язык (ab)*
================================================================
Когда коммутативный образ языка регулярен?
________________________________________________________________
Коммутативный образ языка L регулярен тогда и только тогда, когда кратности вхождений 
γ ∈ Σ в слова из языка L описываются объединением линейных функций.

Так, например, кратности вхождения символов a и b в слова языка a^n b^n являются 
линейными функциями ⇒ коммутативный образ языка регулярен (действительно, коммутативный образ 
такого языка - язык (ab)*). Эту теорему можно использовать для доказательства не контекстно-свободности языка
с использованием теоремы Париха (также известна как теорема Шютценберже).
В то же время ей нельзя пользоваться для доказательства того, что язык контекстно-свободен, 
поскольку коммутативный образ не контекстно-свободного языка может оказаться регулярным: 
например, коммутативный образ языка a^n b^n c^n регулярен, но сам язык не является контекстно-свободным.  
================================================================
Линейные языки в теории формальных языков - это?
________________________________________________________________
Линейный язык (linear language) - это язык, распознаваемый контекстно-свободной грамматикой, 
в которой все правила содержат не больше одного нетерминала в правой части. 
То есть дерево разбора грамматики выглядит следующим образом: среди потомков 
каждого нетерминала может быть лишь один нетерминал, а все остальные потомки - 
терминальные символы.
================================================================
Лемма о накачке для линейных языков
________________________________________________________________
Лемма о накачке для линейных языков (pumping lemma for linear languages):
Пусть L - линейный язык. Тогда существует p > 0, такое, что для любого слова w из языка L 
(где длина w больше p) ⇒ существуют x_0, z_1, y, z_2, x_1 (где длина конкатенации z_1 и z_2 не равна 0), 
такие, что w = x_0 z_1 y z_2 x_1 (при этом длина конкатенации x_0, z_1, z_2, и x_1 меньше либо равна p) 
и для любого натурального числа k слово x_0 z_1^k y z_2^k x_1 принадлежит языку L.

Отличие этой леммы от обычной леммы о накачке для контекстно-свободных языков заключается в ограничении 
на длину конкатенации частей слова:
для обычной леммы должно выполняться, что длина конкатенации z_1, y и z_2 должна быть меньше либо равна p,
тогда как для леммы для линейных языков должно выполянться, что длина конкатенации x_0, z_1, z_2, и x_1 
меньше либо равна p.

Эту лемму можно использовать для доказательства того, что язык не является линейным: в таком случае
можно подобрать слово w из языка L, такое, что для любого разбиения 
w = x_0 z_1 y z_2 x_1 будет существовать константа k из множества натуральных чисел, такая, что
слово x_0 z_1^k y z_2^k x_1 не лежит в языке L.

Опережающая проверка регулярных выражений
________________________________________________________________
Опережающая (lookahead) проверка регулярных выражений используется для проверки 
соответствия (или несоответствия) префикса регулярного выражения заданному шаблому. Обычно позитивная 
опережающая проверка обозначается следующим образом: (?=r1)r2. 
Это выражение эквивалентно следующему: r2 ⋂ (r1.*)
Негативная опережающая проверка обозначается, как (?!r1)r2, и проверяет несоответствие префикса 
выражения r2 шаблону r1. 
Опережающие проверки могут использоваться, например, для проверки соответствия создаваемого пароля заданным условиям:
(?=.*[!@#$%^&*])(?=.*[a-z])[0-9a-z!@#$%^&*]+ - такие опережающие проверки гарантируют, 
что строка будет иметь по крайней мере один специальный символ и одну букву.  
================================================================
Ретроспективная проверка регулярных выражений
________________________________________________________________
Ретроспективная (lookbehind) проверка регулярных выражений является в некотором смысле обратным понятием для 
опережающей проверки. Ретроспективная проверка используется для проверки соответствия (или несоответствия) 
суффикса регулярного выражения заданному шаблону. 
Принятое обозначение для позитивной ретроспективной проверки: r0(?<=r1). Такое выражение эквивалентно r0 ⋂ (.*r1)  
Обозначение негативной ретроспективной проверки: r0(?<!r1)
В случае, если имеется выражение r0(?<=r1)r2, в котором отсутствуют опережающие проверки, то оно эквивалентно
(r2^R (?=r1^R) r0^R)^R, где ^R - обозначение реверса.

Что такое сбалансированная высота дерева разбора контекстно-свободной грамматики?
________________________________________________________________
Пусть G = (Σ, N, R, S) — контекстно-свободная грамматика. Сбалансированная высота (balanced height) 
дерева разбора T с произвольным нетерминальным символом в корне — это натуральное число bh(T), 
определяемое индуктивно по структуре дерева:
- Если корень T помечен нетерминальным символом A из множества нетерминальных символов N и все его потомки — 
термианльные символы (соответствующие правилу A → w, где w - слово из языка Σ∗), то bh(T) = 0.
- Если из корня дерева T исходят поддеревья T_1,..., T_k, и сбалансированная высота одного из них, T_i, 
строго больше, чем у всех остальных (bh(T_i) > bh(T_j) для всех i, не равных j), то bh(T) = bh(T_i). Иначе, 
если максимальная сбалансированная высота среди поддеревьев T_1,..., T_k достигается не менее чем на двух из них, 
то bh(T) = 1 + max(bh(T_i)) по всем i.
Дерево называется компактным, если bh(T) не превосходит числа различных нетерминальных символов в T.
Также у сбалансированной высоты есть другие названия: число Стралера (Strahler’s number) или 
размерность дерева (dimension of a tree).

Ширина последовательности перезаписи - это такое число k, что в каждой сентенциальной форме не более
k нетерминальных символов.
Лемма (свойство дерева разбора для контекстно-свободной грамматики):
Пусть G = (Σ, N, R, S) — контекстно-свободная грамматика, и пусть T — дерево разбора слова w из Σ∗ с корнем
в нетерминальном символе A ∈ N. Пусть d — сбалансированная высота дерева T. Пусть m — наибольшее количество
нетерминальных символов в правой части правил.
Тогда существует последовательность перезаписи из символа A в слово w ширины (m − 1) * d + 1.

Лемма Бадера-Моры для контекстно-свободных языков
________________________________________________________________
Лемма Бадера–Моры: Для всякого языка L, задаваемого контекстно-свободной грамматикой, 
существует такая константа p >= 1, что для любого слова w из языка L
и для всяких двух множеств P, Q, являющихся подмножеством {1,..., |w|} выделенных и исключённых позиций в слове w,
которые удовлетворяют условию: |P| >= p^(|Q|+1), существует разбиение слова w = x u y v z, где
- u v содержит хотя бы одну выделенную позицию и ни одной исключённой;
- если d — число выделенных позиций в u y v, а e — число исключённых позиций в u y v,
то d <= p^(e+1) и x u^i y v^i z лежит в языке L для всех i, больше либо равных 0.

При пустом множестве Q лемма Бадера-Моры сводится к лемме Огдена.

Лемма Соколовского в теории формальных языков
________________________________________________________________
Лемма Соколовского: Пусть L — язык над алфавитом Σ, задаваемый контекстно-свободной грамматикой. 
Пусть Ω — подмножество алфавита Σ, содержащее хотя бы два символа. 
Тогда для всякого подмножества языка L вида {x u y u z | u лежит в языке Ω∗ }, где x, y, z лежат в языке Σ∗,
язык L содержит строку вида x u y v z, где u, v лежат в языке Ω∗ и u не совпадает с v.

Пример:
Приведённая ниже строка, где w, w' ∈ {a, b}+ — правильная программа на языке C
тогда и только тогда, когда w = w'.
main() { int w; w' = 0; }
Из леммы Соколовского следует, что всякая грамматика, которая задаёт такие строки, будет также
порождать другие строки с несоответствующими друг другу именами. Здесь в предыдущих обозначениях:
L - язык, задающий правильные строки приведённого выше вида, Ω = {a, b}, u = w, v = w',
x = "main() { int ", y = "; ", z = " = 0; }". Части исходной строки для x, y и z заключены в двойные кавычки 
для лучшей читаемости.

Теорема Креспи-Реггицци и Сан-Петро в теории формальных языков
________________________________________________________________
Пусть D_k ⊆ Ω_k* — язык Дика над k парами скобок, определённый над
алфавитом Ω_k = {a_1, b_1,..., a_k, b_k}
Теорема Креспи-Реггицци и Сан-Петро:
Для всякого алфавита Σ существует k >= 1 — количество пар скобок, зависящее только от |Σ|, такое, что язык
L, являющийся подмножеством (Σ^2)∗, задаётся контекстно-свободной грамматикой тогда и только тогда,
когда он представим в виде L = h(D_k ∩ R), для некоторого регулярного языка R ⊆ Ω_k* и гомоморфизма h: Ω_k → Σ, 
который сохраняет длину.
